Smart Stock Tracker Using IoT

Project Overview : 
Smart Stock Tracker using IoT is an intelligent system developed to automate real-time stock monitoring in government ration shops and improve communication with elderly beneficiaries.The system reduces manual errors, prevents stock mismanagement, and ensures transparency in public distributionThis project combines IoT, Computer Vision, Machine Learning, and SMS alerts to create a reliable and user-friendly solution.

Problem Statement:
Traditional ration shops rely on manual stock entry and record maintenance, which leads to:
Stock mismatches and shortages
Delayed updates for beneficiaries
Difficulty for elderly people to know stock availability

Solution:
The proposed system:
Automatically tracks stock levels in real time
Uses camera-based monitoring to identify items
Sends SMS notifications to elderly recipients
Improves transparency and efficiency in ration distribution

 System Features:
 1.Real-Time Stock Tracking
 2.Image Processing for Item Detection (OpenCV)
 3.Machine Learning Model for Stock Classification (TensorFlow)
 4.Automated SMS Alerts using Twilio API
 5.Elderly-Friendly Communication System
 6.Reduced Human Errors & Fraud Prevention

🛠️ Technologies Used:
Technology	  Purpose
Python	      Core application development
IoT Devices	  Stock monitoring
OpenCV	      Image processing & item recognition
TensorFlow	  ML-based classification
Twilio API	  SMS alerts to beneficiaries

⚙️ System Architecture:
IoT sensors and cameras monitor ration stock
OpenCV processes captured images
TensorFlow model identifies and verifies stock items
Stock data is updated automatically
SMS notifications are sent to registered elderly users
